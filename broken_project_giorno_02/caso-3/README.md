# Caso 3

## Sintomo

Le run non si somigliano. Sullo stesso repository, la stessa suite a volte chiude in un minuto e a volte ne impiega dieci; certe volte i rilievi sono completi, altre volte si fermano a metà di un file senza che il report dica perché.

Chiedendo al team di prevedere quanto durerà la prossima, nessuno sa rispondere. E alla domanda *«qual è il massimo che può durare?»* la risposta è un'alzata di spalle.

Cerca nel codice il numero che stabilisce dove ci si ferma. **Non c'è.**
