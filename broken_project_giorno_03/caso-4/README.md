# Caso 4

## Sintomo

Il server parte, risponde, e dal tuo portatile funziona tutto.

Poi un collega, dalla sua macchina in ufficio, prova a curiosare: apre l'indirizzo del tuo server, chiede l'elenco degli strumenti, e ottiene i saldi di un conto. Non gli è stato chiesto niente.

Non è un difetto che si vede provando il proprio lavoro, perché dalla propria macchina il comportamento è identico. Si vede **da un'altra macchina** — o in audit.
