# Caso 2

## Sintomo

Il server è collegato, il tool compare nell'elenco di quelli disponibili, e chiamandolo a mano funziona.

Eppure durante le review non viene usato **mai**. Il reviewer guarda il codice, dice la sua sui saldi ragionando solo su quello che legge, e il dato vero non va a prenderlo — pur avendo a disposizione lo strumento per farlo.

Non è un problema di permessi: il tool c'è ed è invocabile. È che nessuno lo invoca.
