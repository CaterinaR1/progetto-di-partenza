# Caso 1

## Sintomo

Lanci la suite su una codebase grande e vai a prendere un caffè. Torni mezz'ora dopo e sta ancora girando.

Quando finalmente finisce, il report c'è ed è pure buono. Il problema si vede il mese dopo, sulla fattura: quella singola run è costata come venti delle altre, e nessuno se ne era accorto mentre succedeva. Ripetuto su cento run al mese, è la voce di spesa che qualcuno ti chiederà di giustificare.

La domanda non è perché quella run sia costata tanto. È: **cosa avrebbe dovuto fermarla?**
