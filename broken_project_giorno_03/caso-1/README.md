# Caso 1

## Sintomo

Il tool è esposto e il modello lo chiama volentieri. Solo che gli passa quasi sempre qualcosa che non c'entra: una volta una chiave inventata, una volta un oggetto vuoto, una volta il numero giusto ma sotto un nome che il tool non conosce.

La risposta che torna è vuota o senza senso, e il modello ci costruisce sopra la sua conclusione.

Guarda il tool con gli occhi di chi deve chiamarlo senza aver letto il codice: **da cosa dovrebbe capire cosa passargli?**
